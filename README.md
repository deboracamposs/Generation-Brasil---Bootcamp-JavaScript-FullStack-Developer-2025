## 🌟 Sobre o Repositório

Este repositório é dedicado ao registro e organização de todo os exercícios e desafios desenvolvidos durante o **Bootcamp JavaScript FullStack Developer 2025** oferecido pela Generation Brasil.

O objetivo principal é:

* **Centralizar o aprendizado** e servir como um diário de bordo técnico.
* **Demonstrar o progresso** e as habilidades adquiridas nas trilhas de **Front-end** e **Back-end**.
* **Servir como Portfólio** para recrutadores e demais interessados na minha jornada de desenvolvimento.

---

## 💻 Tecnologias e Módulos Abordados

Abaixo estão listadas as principais tecnologias, frameworks e tópicos que serão (ou já foram) explorados ao longo do Bootcamp:

| Categoria | Tópicos e Tecnologias |
| :--- | :--- |
| **Lógica e Fundamentos** | Lógica de Programação, Algoritmos, Estrutura de Dados, Programação Orientada a Objetos (POO). |
| **Front-end** | HTML5, CSS3, JavaScript (ES6+), React, Hooks, Gerenciamento de Estado. |
| **Back-end** | Node.js, Express, REST APIs, Autenticação (JWT). |
| **Banco de Dados** | SQL (MySQL ou PostgreSQL), NoSQL (MongoDB), Mongoose/Sequelize. |
| **Ferramentas** | Git, GitHub, VS Code, Metodologias Ágeis. |

## ⚙️ Como Clonar e Executar

Se você deseja explorar os projetos e exercícios localmente, siga os passos abaixo.

### Pré-requisitos

* **Node.js e npm** 
* **Git**

### Passos

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/deboracamposs/Generation-Brasil---Bootcamp-JavaScript-FullStack-Developer-2025.git](https://github.com/deboracamposs/Generation-Brasil---Bootcamp-JavaScript-FullStack-Developer-2025.git)
    ```
2.  **Acesse a pasta do repositório:**
    ```bash
    cd Generation-Brasil---Bootcamp-JavaScript-FullStack-Developer-2025
    ```
3.  **Entre na pasta de um projeto específico (exemplo):**
    ```bash
    cd 03-modulo-back-end/api-rest-blog-pessoal
    ```
4.  **Instale as dependências (se houver):**
    ```bash
    npm install
    ```
5.  **Execute o projeto:**
    ```bash
    npm start
    ```
